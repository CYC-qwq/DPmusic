🎵 DPmusic 功能总览

一、音源与内容（三平台聚合：网易云 / QQ音乐 / 酷狗）
能力	说明
歌曲搜索	三平台并行搜索，平台切换 + 分页加载
歌单搜索	关键词搜歌单（QQ 匿名态自动降级分类浏览）
歌曲链接解析	粘贴官方分享链接 → 自动识别平台并定位歌曲
歌单链接导入	三平台歌单链接 → 保存为「链接歌单」（可更新）
榜单	三平台官方热榜浏览 + 榜单详情
歌词获取	逐行 LRC + 翻译合并（±400ms 对齐）
封面	三平台封面获取（酷狗走 union_cover 兜底）
酷狗概念版音源	酷狗概念版（lite）第四条解析通道，可拿 VIP / 高音质直链；设置页「酷狗概念版音源」卡片开关 + 默认「优先使用」；登录用手机号 + 短信验证码（不代持密码）；每日自动签到领 VIP（默认关闭、含风控风险提示）

二、播放（Media3 / ExoPlayer + MediaSessionService）
• 后台保活：通知栏 / 锁屏 / 耳机按键控制；音频焦点、拔耳机自动暂停、网络唤醒
• 播放控制：播放暂停 / 上下首 / 进度拖拽（时间气泡）/ 循环（关·列表·单曲）/ 随机 / 队列跳播
• 播放队列：面板支持搜索过滤、点击跳播、当前曲高亮、全部加入歌单；懒解析（仅当前+下一首持有真实地址）
• 音质体系：5 档可选 + 失败自动逐级降档链 + 8 分钟 URL 缓存 + 熔断器
• 跨平台兜底：同平台彻底失败后，按标题/歌手相似度到其它平台换源
• 错误自愈：失败自动重解析重试；同曲连续失败 2 次自动跳过并提示
• 续播：主页「继续收听」+ 播放会话持久化（每 20s 落盘，杀进程可恢复）
• 历史回写：切歌/暂停记录进度

三、歌词
• 逐字歌词（卡拉OK）：QQ QRC（自定义 DES 解密）/ 网易云 YRC / 酷狗 KRC 三平台全支持；无逐字数据自动回退行级
• 预测式平滑：填充与人声精确同步（修复了此前恒定慢一个字的问题）
• 交互：点击行 seek、自动滚动（拖动暂停 / 松手 4s 恢复）、歌词模式全屏切换
• 样式调节：字号 / 行距（横竖屏分别记忆持久化）
• 行级动效：颜色 / 缩放 / 透明度阻尼过渡 + 翻译行显示

四、听歌识曲 🎤
• 两种模式（可切换）：听歌识曲（识别环境音/内录播放的歌曲）/ 哼歌识曲（自己哼旋律识曲）
• 引擎随模式不同：听歌 = 三引擎并行（QQ + 酷狗 + 网易云）；哼唱 = **仅 QQ**（酷狗/网易云无哼唱通道）
• 三种拾音方式：麦克风（环境音）/ 系统内录（Android 10+ MediaProjection）/ 音频文件（SAF）
• 采集 12 秒（哼唱 15 秒）→ 听歌三引擎并行 / 哼唱仅 QQ（Base64 PCM）
• 结果操作：播放 / 收藏 / 长按加歌单；支持「找原唱」版本搜索
• 音频仅内存处理，不落盘
• QQ音乐（2026-09 起接入，听歌/哼唱双模式）：客户端逆向出 `c6.y.qq.com/youtu/humming/search`，
  请求体为 **Base64(8k/16bit/mono PCM)**，**零签名、零 Cookie、匿名可用**；
  听歌/哼唱靠 URL `fpType` 区分（听歌=5 / 哼唱=4，源码级证据：`TAB_MUSIC`/`TAB_HUMMING` 分流）；
  实测 3 首真歌 100% 命中（孙燕姿《我不难过》/ 采风乐坊《蓄勢》/ 杨丞琳《雨爱》）；
  详见 AUDIO-RECOGNIZE-RESEARCH.md §7.7

五、评论 💬
• 歌曲评论区：热门评论 + 最新评论分区展示，分页「加载更多」
• 平台覆盖：网易云 / QQ 音乐；酷狗评论接口需签名，暂不支持（显示明确空态）
• 楼中楼回复：带回复的评论显示「查看 N 条回复」入口，默认折叠、点击平滑展开
• 回复展开状态按评论 id 记忆，列表滚动 / 翻页不丢

六、下载
• 音质选择（解析失败自动降档并提示）
• 可选同时下载歌词（.lrc，含翻译行）
• 下载进度显示 / 可取消 / 完成失败反馈；支持跨平台换源
• 下载路径自定义：可写性校验 + 权限引导（所有文件访问 / 存储权限）+ 恢复默认

六、分享
• 歌曲分享：三种组合 —— 官方链接 / 音源直链（实时解析）/ 两者都带 → 系统分享面板
• 歌单分享：JSON 备份文件（系统分享）/ 源链接分享 / 复制链接 / 导出文件（SAF）

七、本地歌单管理
• 创建 / 重命名 / 删除
• 链接歌单：从链接更新 + 定时更新（关闭 / 每天 / 每3天 / 每周，打开歌单页自动检查）
• 导入导出：JSON 备份（SAF）；外部「用其他应用打开」JSON 自动导入
• 歌单详情：全部播放 / 过滤 / 多选批量操作（加歌单、批量移除）/ 逐行移除

八、收藏与历史
• 我的喜欢：滑动移除 / 下一首播放
• 最近播放：时间轴分组 + 进度胶囊、续播、全部播放、清空
• 听歌统计：本次播放时长 + 近 7 日每日时长柱状图

九、剪贴板与导入
• 剪贴板自动读取（可开关）：切回 App 时检测歌曲 / 歌单链接 → 弹窗确认处理
• 搜索框粘贴链接自动识别解析
• JSON 备份通过「打开方式 / 分享」导入

十、音效与音频增强 🎛
• 总开关 + 实时频段响应曲线 + 垂直推子（拖动/点击定位）
• 10 段参数均衡器（Media3 AudioProcessor 链，RBJ 双二阶滤波）+ 自动预增益防削顶
• 7 种中文预设（正常/流行/摇滚/爵士/古典/人声/重低音）+ 自定义
• 低音增强、立体声宽度滑杆（M/S 扩展）+ 重置
• USB 独占输出（Bit-Perfect，Android 14+）：为外接 USB DAC 申请系统级 bit-perfect 混音属性，
  绕过系统混音器直通输出；设置内可开关，独占期间自动旁路均衡器；拔插自动感知
• 播放页示波器：FFT 频谱柱（48 根对数分桶）+ 实时波形（过零触发）；设置内可开关，
  可选「频谱柱 / 波形 / 两者」；100Hz 数据刷新 + 逐帧缓动，无卡片背景直接融入流光底
• 设置持久化，随播放会话自动挂载生效

十一、界面与全设备自适应
• 五大页签：主页 / 搜索 / 榜单 / 歌单 / 我的
• 主页：时段问候 + 继续收听 + 快捷卡（喜欢/歌单）+ 三平台热榜速览 + 识曲入口
• 自适应：手机底部导航 ⇄ 平板/横屏侧边栏「变形演进」；单栏 ⇄ Master-Detail 双栏；旋转不重建、滚动位置保持
• 播放器双形态：竖屏（黑胶+迷你歌词窗）⇄ 横屏（左封面右全屏歌词黄金分割）；Mini 条 ⇄ 全屏流体形变 + 封面共享元素动画；预测性返回手势跟手折叠
• 主题：M3 动态取色（Android 12+）/ 内置主题色板 / 深色三态（跟随系统·浅·深）
• 动效：封面取色流光背景、黑胶旋转呼吸、交错入场、按压反馈

十二、系统集成
• 媒体通知 / 锁屏控制 / 耳机按键
• 双前台服务：媒体播放 + 屏幕捕获（识曲内录）
• FileProvider 文件分享；通知权限（13+）/ 录音 / 存储权限按需申请
